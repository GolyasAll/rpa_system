# Bem-vindo ao Projeto RPA_System

O **Prata System**, como foi carinhosamente apelidado, é uma aplicação de automação robótica de processos (RPA) voltada à extração estruturada de informações do Simplo Online. Por meio de um painel web centralizado, o usuário inicia e acompanha a coleta de dados de manuais, montadoras, modelos, índices e capítulos, gerando relatórios.

## Tecnologias

- **Python** e **Flask** para a aplicação e a API web;
- **Selenium** para automação do navegador e navegação na plataforma;
- **OpenPyXL** para criação e exportação dos relatórios `.xlsx`;
- **HTML, CSS, JavaScript** e **Tailwind CSS** para a interface e o acompanhamento da execução em tempo real.

## Objetivos

- Centralizar e agilizar a coleta de informações técnicas;
- Reduzir atividades manuais e a possibilidade de erros operacionais;
- Permitir a seleção do escopo da extração por meio do painel;
- Disponibilizar os dados coletados em relatórios organizados para consulta e análise.
